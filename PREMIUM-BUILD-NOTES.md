# Premium build notes

This build keeps the existing React/Vite + Express/MongoDB architecture and improves its presentation layer and real supplied content without claiming that an expensive design automatically has a particular monetary value.

## Included

- Jamia-tur-Raza Ghousia Mehria branding and the supplied logo, cleaned/optimized where possible.
- English/Urdu language switch, public RTL behavior, and bilingual program/notice content fields.
- Owner & Principal profile with the supplied portrait.
- Supplied phone/WhatsApp/email/address and the Google Maps link provided by the client.
- Seven programme types: Hifz-ul-Qur’an, Nazra Qur’an, Tajweed, Teaching Program, Dars-e-Nizami, Qira’at, and Islamic Studies.
- Year-round admissions information, B-Form and father's CNIC-copy checklist, and boys' hostel details.
- Locally hosted event photos and custom SVG programme illustrations; compressed additional posters are archived separately for review.
- Responsive Home, About, Programmes, Gallery, Admissions and Contact pages.
- Contact/enquiry form, existing API integration, admin authentication/dashboard, seed script for seven courses and year-round notice.
- SEO metadata, PNG social-sharing image, PWA icons/manifest, organization JSON-LD, focus states, skip link, and a bilingual draft privacy notice.
- Single-service Dockerfile, Docker Compose with a root `.env`, Render Blueprint, and deployment guides.

## Still required before launch

- Approve the exact Urdu spelling and all public-facing contact data.
- Verify the supplied Maps URL resolves to the intended gate/building pin.
- Confirm programme syllabuses, stages, ages/eligibility, timings, fees, and hostel rules/charges.
- Review consent for event photographs, particularly images of children.
- Configure production database, secrets, deployment origin/CORS, HTTPS and backups; review/approve the included privacy notice.
- Complete a production build and full browser/mobile/end-to-end test in the client's environment.
